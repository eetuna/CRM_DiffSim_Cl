The hybrid controller calls MPC at 100% of timesteps (vs. target ≤30%).

ROOT CAUSE:
  Ensemble was trained on synthetic golden data (smooth trajectories, ~2mm error)
  Real NPZ data is significantly harder (complex trajectories, ~44mm error)
  
  → Ensemble correctly detects out-of-distribution states
  → High uncertainty triggers MPC fallback at every step
  → No speedup benefit, only overhead

EVIDENCE:
  • Hybrid RMSE = MPC RMSE exactly (policy never executed)
  • Real data baseline error 22× higher than golden data (44mm vs 2mm)
  • 100% MPC call rate = uncertainty always above threshold
